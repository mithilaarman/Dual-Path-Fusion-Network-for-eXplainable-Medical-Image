Official implementation of **Dual-Path-Fusion-Network-for-eXplainable-Medical-Image**, a lightweight dual-path framework for explainable medical image classification.

The proposed model, **P2FNet**, combines complementary **local fine-grained features** and **global semantic information** through an efficient late-fusion strategy. The framework is evaluated across six public medical imaging datasets representing multiple imaging modalities.

---

## 🔍 Overview

Medical image classification requires models to capture both subtle localized pathological patterns and broader contextual information.

Convolutional architectures are particularly effective at capturing local spatial features, while global representations are important for modeling high-level semantic context.

To exploit these complementary properties, the proposed framework uses two parallel feature extraction pathways:

1. **Global Feature Extractor (GFE)**
2. **Local Feature Extractor (LFE)**

The feature representations generated by the two branches are combined through **channel-wise late fusion** before final classification.

---

## 🧠 Architecture

The framework consists of two complementary feature extraction branches.

### Global Feature Extractor

The **Global Feature Extractor (GFE)** uses a pretrained **MobileNetV2** backbone to capture high-level semantic information and broader spatial context.

### Local Feature Extractor

The **Local Feature Extractor (LFE)** is designed to capture fine-grained pathological patterns using:

* Depthwise Separable Convolutions
* Squeeze-and-Excitation (SE) blocks
* Residual connections

### Late Feature Fusion

Both feature streams are passed through **Global Average Pooling**.

The resulting global and local feature vectors are then concatenated through channel-wise fusion before classification.

```text
                    Input Image
                         │
             ┌───────────┴───────────┐
             │                       │
             ▼                       ▼
     Global Feature             Local Feature
       Extractor                  Extractor
     (MobileNetV2)         (Depthwise Conv + SE)
             │                       │
             ▼                       ▼
     Global Average             Global Average
        Pooling                    Pooling
             │                       │
             └───────────┬───────────┘
                         │
                         ▼
                Channel-wise Fusion
                         │
                         ▼
                 Fully Connected
                    Classifier
                         │
                         ▼
                    Prediction
```

The architecture is designed to preserve the complementary characteristics of local and global representations while maintaining relatively low computational complexity.

## ⚙️ Image Preprocessing

All input images are resized to:

```text
224 × 224
```

For pretrained architectures, standard ImageNet normalization is used:

```python
mean = [0.485, 0.456, 0.406]
std  = [0.229, 0.224, 0.225]
```

For the custom model pipeline, pixel values are rescaled to the `[0, 1]` range.

## 🔬 Ablation Study

Ablation experiments on the **APTOS dataset** evaluate the contribution of the individual feature streams and different fusion strategies.

| Architecture               |   Accuracy |   F1-Score |
| -------------------------- | ---------: | ---------: |
| Local Stream Only          |     97.82% |     97.81% |
| Global Stream Only         |     98.09% |     98.07% |
| Early Fusion               |     97.45% |     97.43% |
| Mid-Level Fusion           |     97.83% |     97.80% |
| Multi-Scale Fusion         |     98.30% |     98.29% |
| **Late Fusion (Proposed)** | **98.64%** | **98.62%** |

The results show that the local and global streams provide complementary information.

Among the evaluated fusion approaches, **late fusion produces the strongest performance**.
